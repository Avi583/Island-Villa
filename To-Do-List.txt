1. NOT YET TESTED
---------------------------------------------------------------------
1a. [ ] Performance on a real multi-core desktop.
    Only tested in a 2-core sandbox (about 5-12 fps at ~230x130 internal
    resolution). On 8+ thread machines it should be much higher, but the
    actual fps, the resolution auto-scaling behaviour and the 36 ms frame
    target in "Balanced" mode have not been measured on real hardware.

1b. [ ] Browsers other than Chromium.
    Not tested in Firefox, Safari (macOS / iOS) or Edge. Things to check:
      - WebAssembly SIMD support (build uses -msimd128; Safari needs 16.4+)
      - canvas ctx.filter used by the bloom pass (older Safari ignores it,
        so bloom would silently not appear; the page should still work)
      - pointer lock behaviour for mouse look

1c. [ ] Mobile / touch controls.
    Left-half drag = move, right-half drag = look. Written but never run on
    a phone or tablet. Also check memory use (one WASM instance per core).

1d. [ ] Live GitHub Pages deployment.
    Local static serving was verified (all files return 200 and the .wasm is
    served as application/wasm), but the site has not been pushed to GitHub
    or opened from a github.io URL yet.

1e. [ ] Google Fonts loading.
    Blocked inside the build sandbox, so the fonts (Space Grotesk, JetBrains
    Mono) were never seen loading. The page falls back to system fonts if
    they fail, so this is cosmetic only.

1f. [ ] Long-running stability.
    Not soak-tested (e.g. 10+ minutes of walking, repeated window resizes,
    switching quality modes many times) for memory growth or stalls.

1g. [ ] Screenshot and Fullscreen buttons.
    Wired up but never clicked in a real browser session.

1h. [ ] Collision edge cases.
    Walking onto / off the boardwalk dock, sliding along the glass walls and
    around pillars, trees and lamps has only been reasoned through in code,
    not walked in the browser.

Frame pipeline (main.js / worker.js)
(3a and 3b done - see 5u and 5v.)

Ray tracer (C++)
3g. [ ] (SONNET) Island cylinder is inside the BVH.
    It is a 48 m wide primitive whose box covers the whole scene, so
    whichever BVH node holds it is huge and nearly every ray descends into
    it. Intersect it analytically in intersectScene() like the lake plane.
    Also test the lake/sand planes BEFORE BVH traversal so the tighter
    tmax prunes BVH nodes behind the water.

3h. [ ] (SONNET) BVH nodes are box-tested twice.
    traverse() tests both children's boxes before pushing them, then tests
    the popped node's box again. Push the entry distance with the node and,
    on pop, skip it only if tnear >= h.t (no second slab test).

3k. [ ] (OPUS) Glass and water always trace both reflection and transmission.
    Every front-facing glass hit at depth < 4 spawns a shadeReflection()
    (up to 4 more intersections + lighting) even though F is ~4.5% and
    the ray usually passes through 2+ panes. Pick reflection OR
    transmission stochastically by F (weighted), or skip the reflection
    when F * throughput is tiny.

(3l done - see 5w.)

(3m and 3n done - see 5x.)

3o. [ ] (OPUS) Ray packets for primary rays.
    BVH4 (5x) uses SIMD across 4 child boxes for one ray. Tracing 2x2
    camera rays as a packet could add more speed for the first bounce,
    but shading is recursive per ray, so it means restructuring rt_render.

5k. [x] Workers sit idle between frames (fixed Oct 26, 2026).
5l. [x] Bilateral denoise moved from JS main thread to WebGL pass (JS kept

5m. [x] GI costs full price at low weight (fixed; JS only, no rebuild).
5n. [x] Pool rim added: tile coping lip around the water, and bare cap strips
    at the pool ends filled (wasm rebuilt; not yet viewed in a browser).
5o. [x] Haze/fog only computed when fog > 0 (wasm rebuilt; fps not measured).
5p. [x] Sky halo uses multiplies instead of pow (wasm rebuilt; fps not
    measured).
5q. [x] (3c) Auto-resolution: render width snapped to 16 px steps, plus an
    8-frame cooldown between scale changes. Not yet run in a browser.
5r. [x] (3d) Rendering idles once a frozen (Photo/paused), still image reaches
    512 samples; wakes on any camera/sun/exposure/quality change. Not yet run
    in a browser.
5s. [x] (3e) Worker count is now hardwareConcurrency - 1 (min 2). fps impact
    not measured; compare on real hardware (see 1a).
5t. [x] (3f) Panel backdrop-filter removed; background made more opaque
    (0.62 -> 0.8 alpha). Not yet viewed in a browser.
5u. [x] (3a) The visible #view canvas is now the WebGL canvas (no drawImage
    copy; preserveDrawingBuffer keeps Screenshot working). A 2D context is
    only created when WebGL is unavailable. Not yet run in a browser.
5v. [x] (3b) Bloom runs in the WebGL pass: 9-tap separable blur on a 1/4-size
    copy, added in the upscale shader. The CSS-filter bloom remains only in
    the no-WebGL fallback. Still uniform, not thresholded (see 2d). Not yet
    run in a browser; check the glow strength against the old look.
5w. [x] (3l) Gamma now uses a 4096-entry lookup table (linearly interpolated)
    built in rt_init() instead of 3 pow calls per pixel. wasm rebuilt cleanly;
    not yet viewed in a browser and fps not measured.
5x. [x] (3m, 3n) The binary SAH BVH is collapsed into a 4-wide BVH (BVH4)
    whose child boxes are tested with one WASM SIMD slab test, and prims[]
    is reordered into leaf order (no idx[] lookup). Node.js benchmark,
    640x360, 3 views: ~560-680 ms -> ~400 ms (~30-40% faster). Pixels
    match the old build except 15 isolated ones out of 691,200, all on
    reflective or glass surfaces; most likely equal-distance ties now
    resolved in a different order. Not yet viewed in a browser.
5y. [x] (2a) Soft/blocky image while moving on slow CPUs. Auto-resolution
    floor raised from 18% to 30% scale (MIN_SCALE), render width never below
    320 px (was 160) and height never below 180 px (was 90); the Render scale
    slider now starts at 30. GI was already off while moving (Balanced
    giMove = 0). Slow CPUs will now run slower than the 36 ms target instead
    of dropping resolution further. JS only, no rebuild. Not yet run in a
    browser; check fps and sharpness on a slow machine (see 1a).
5z. [x] (2b) Grainy glass/interior while moving. New GPU temporal
    reprojection pass (TAA) before the denoise: the C++ tracer writes a
    per-pixel depth to the first non-glass surface (so the interior behind
    the glass reprojects correctly), each pixel is projected into the last
    shown camera, and the history there is clamped to the current 3x3
    neighbourhood and blended in (1/8 new frame while moving). When the
    camera stops, the WASM running average takes over within 8 frames.
    Needs OES_texture_float; without it (or without WebGL) frames are shown
    as before. wasm rebuilt. Headless Chrome (SwiftShader) A/B while walking:
    the speckle on the interior behind the glass is gone; slight softening /
    short trails on edges in motion. Not yet checked on real hardware; tune
    TAA_ALPHA in main.js if ghosting shows (higher = less ghosting, more
    noise).
